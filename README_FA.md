# پروژه اندروید پنل اضافه‌کاری

این پروژه سورس Android WebView به‌همراه فایل HTML پنل فعلی است. محاسبات و داده‌ها در WebView و با localStorage نگهداری می‌شوند؛ امکانات پشتیبان‌گیری/بازیابی و حذف کاربر داخل پنل حفظ شده‌اند. برای دریافت تعطیلات رسمی، اینترنت لازم است؛ باقی بخش‌ها به‌صورت محلی اجرا می‌شوند.

## ساخت APK با GitHub Actions
1. ZIP را استخراج کنید.
2. محتویات پوشه پروژه (خود فایل‌ها و پوشه `.github`) را در یک مخزن GitHub جدید آپلود کنید.
3. در مخزن وارد تب **Actions** شوید و workflow با نام **Build Android APK** را اجرا کنید؛ یا یک commit بفرستید تا خودکار اجرا شود.
4. پس از اتمام موفق، وارد اجرای workflow شوید و از بخش **Artifacts** فایل `overtime-panel-debug-apk` را دانلود کنید. APK داخل ZIP نیست؛ GitHub آن را می‌سازد.

## ساخت محلی
پروژه را با Android Studio باز کنید و Gradle Sync سپس Build > Build APK(s) را اجرا کنید. نیازمند Android SDK و JDK 17 است.

## نکته
این نسخه APK امضا‌شده برای انتشار فروشگاهی نیست؛ خروجی GitHub یک debug APK قابل نصب برای آزمایش است. قبل از استفاده رسمی، روی گوشی تست کنید و از داده‌ها فایل پشتیبان بگیرید.
